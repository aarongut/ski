# Ski

## [ski.aarongutierrez.com](https://ski.aarongutierrez.com)

A portfolio site for my ski photography. Built with Astro, PhotoSwipe, sharp, and <3

```sh
vp run dev      # develop
vp run images   # process photos in img/original/, then fill in the TODOs in data.json
vp run deploy   # build and publish
```
